# Get3W Desktop

在设置中配置个人模型 Provider，选择工作区后开始聊天。只授予任务需要的文件和电脑控制权限。历史会话和本地文件保持在本机。

## 模型与扩展

支持个人 API Key、本地模型及兼容 Provider。MCP、技能和插件在设置中管理；连接失败时检查地址、凭据与运行状态。不要把密钥写进聊天或提交到仓库。

## Get3W 账户

在账户设置中启动浏览器登录，再连接 Desktop。账户和云设置走 Get3W 服务；退出或切换账户不会删除本地工作区与历史。

## 语言

简体中文为默认语言，设置中可切换英文。

## 版本范围

此版本不提供组织管理、企业 Gateway、云端应用和旧 Den 控制台。历史消息仍可阅读，本地附件和产物仍可使用。没有已验证的公开更新服务时，更新和恢复安装保持不可用。
